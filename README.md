# CHIP-8
 Chip-8 is a virtual machine designed in 1977 for programming video games. This is my attempt to recreate this virtual computer in C

 Chip-8 was created to ease the development of video games for the pcs of that era. People would make programs/games for this virtual machine, and then an interpreter would decode the instructions. The same programs can be run on different computers if they have the interpreter to translate these instructions.
 What i made is actually one of those interpreters.
